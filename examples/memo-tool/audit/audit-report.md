# 監査報告書:業務メモ整理ツール(memo-tool)

発行日:2026-08-07 / 報告書番号:MEMO-20260807-002

## 1. 経営要約

**監査意見:条件付き稼働可**

初回の欠陥fixtureから検出した破壊的削除、入力検証不足、リンク追跡、競合などを修正し、最終コードは9件の受入試験に合格、同一Codexセッションによる全体再検証で新規・残存Must-fixなしとなった。

条件はmacOS/Linuxでの単独利用、個人情報を含めない運用、封印照合成功である。専用SAST/secret scannerと人間の専門監査は未実施であるため、無条件の安全保証ではない。

## 2. 対象と目的

UTF-8・小文字`.txt`・`memos/`直下の通常ファイルを検索し、指定日数を超えたメモを`archive/`へ原子的に移動するローカルCLI。外部通信とテレメトリを行わない。

## 3. 範囲と同一性

- 対象ファイルとSHA-256:`audit/seal.json`
- 対象:sealに列挙された全追跡ファイル
- 除外:`audit/`、`atlas/`（生成された証拠・説明資料）
- 確認:`python3 scripts/audit_guard.py verify-seal examples/memo-tool examples/memo-tool/audit/seal.json`

## 4. リスクと保証水準

- 影響度:低 / データ機密度:中 / 自律性:低 → 標準メニュー
- 保証水準:実施した検査範囲での限定的保証
- 監査意見:条件付き稼働可

## 5. 方法

- 仕様・禁止事項とコードの突合
- 異系統AI（OpenAI Codex）による読み取り専用の独立監査
- 9件の受入試験
- 隔離fixtureによる逆向き検証
- seal v2による全対象ファイルの改変検知

OWASP ASVS、CWE、デジタル庁標準ガイドライン、NIST AI RMF等を参照した独自基準であり、認証・準拠を意味しない。

## 7. 主な改善

- 削除処理を廃止し、macOS `renameatx_np(RENAME_EXCL)` / Linux `renameat2(RENAME_NOREPLACE)`による原子的な非上書き移動へ変更
- ディレクトリFD、`O_NOFOLLOW`、`fstat`でシンボリックリンクと種別を検査
- 空検索、余分な引数、負数・巨大日数、未知コマンドを拒否
- 部分失敗を終了コード1として通知
- 行末の空白・タブを保持
- 逆向き検証で欠陥fixtureが確実に拒否されることを確認

## 8. 残余リスクと利用条件

- 実行中に別プロセスが`memos/` / `archive/`を変更しないこと
- 対応OSはmacOS/Linux。非対応OSは安全側に失敗する
- 個人情報をメモへ含めない
- 専用SAST/secret scanner、人間の専門家によるレビューは未実施
- 静的なseal/HTMLは後日の変更を自動検知しないため、再利用前に検証コマンドを実行する

全件は`audit/unverified-ledger.md`を参照。

## 9. 有効期限

seal検証が1件でも差分を報告した時点、用途・データ区分・OS前提を変更した時点、または1年経過時に再監査する。外部共有前に証拠一式の秘密情報検査を行う。
