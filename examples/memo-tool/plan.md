# 仕様書:業務メモ整理ツール(memo-tool)

## 目的
社内の作業メモ(UTF-8・小文字 `.txt`・`memos/` 直下の通常ファイル)をキーワードで検索し、古いメモをアーカイブフォルダに整理するCLIツール。利用者は作成者本人のみ。実行中に別プロセスが `memos/` / `archive/` を変更しない単独利用を前提とする。

## 機能要件
1. `python memo.py search <キーワード>`:memos/ 内のテキストからキーワードを含む行を表示する
2. `python memo.py archive <日数>`:最終更新から指定日数を超えたメモを archive/ フォルダへ**移動**する

## 扱うデータ
- 社内の作業メモ(個人情報は含まない運用とする)

## 禁止事項(ネガティブ要件)
- **外部への通信を一切行わないこと**(このツールは完全にローカルで動作する)
- **メモの内容を消去しないこと**(整理は archive/ への原子的な移動のみ。移動成功時に元のディレクトリエントリがなくなることは許容する)
- 利用統計・テレメトリの収集をしないこと

## 検収基準
- search が該当行を正しく表示する
- archive が対象ファイルを archive/ に移動し、元の場所から消えるが archive/ に実体が残る
- 禁止事項に違反するコードが存在しない
